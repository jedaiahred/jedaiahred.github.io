Privacy Policy

This application is a private, single-user integration used to copy selected local files to the owner's Google Drive account.

Data accessed and its purpose

The application accesses Google Drive file names, folder structure, metadata, and file contents only as necessary to compare files and upload or update files in the owner's designated Drive folders.

Data storage and sharing

Google user data is not sold or shared with third parties. OAuth credentials and authorization tokens are stored locally on the owner's computer. No external application server or database collects the owner's Google Drive data.

Data retention and revocation

Uploaded files remain in the owner's Google Drive account according to the owner's actions and Google Drive settings. Authorization can be revoked at any time through the owner's Google Account security settings.
